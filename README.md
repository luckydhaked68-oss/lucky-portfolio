# Lucky Dhaked Portfolio — Separate Components

The portfolio is split into separate React files so every section can be edited independently.

## Structure

- `src/App.jsx` — main app composition
- `src/main.jsx` — React entry point
- `src/index.css` — global styles
- `src/pages/Home.jsx` — page composition
- `src/components/Navbar.jsx` — navbar + mobile menu
- `src/components/Hero.jsx` — hero section
- `src/components/About.jsx` — about section
- `src/components/Skills.jsx` — skills section
- `src/components/Projects.jsx` — projects section
- `src/components/Experience.jsx` — experience/timeline section
- `src/components/Contact.jsx` — contact section
- `src/components/Footer.jsx` — footer
- `src/data/portfolioData.js` — nav links, skills, projects and experience data
- `src/assets/` — logo, profile and project images

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
